# PokeSurvivor Nexus fase 1, plan de implementación

**Objetivo:** cascarón de extensión con autoactualización desde GitHub y mod con cinco módulos.
**Spec:** `docs/superpowers/specs/2026-10-31-nexus-fase1-design.md`
**Stack:** Chrome MV3 (`userScripts`, `scripting`, `storage`, `alarms`), JavaScript sin dependencias, Node 24 para el build.

## Restricciones globales

- Dominios del juego: `https://pokesurvivor.com/*` y `https://www.pokesurvivor.com/*`.
- Canal remoto: `https://raw.githubusercontent.com/darvinh12/pokesurvivor-nexus/main/dist/`.
- Prefijo de `localStorage`: `nexus:`. Guardián global: `window.__nexus`.
- Cabecera obligatoria de `mod.js`: `/*! PokeSurvivor Nexus v<versión> */`.
- Commits sin ninguna mención a IA.

## Contrato interno del mod (compartido por todos los archivos de `src/`)

Todos los archivos de `src/` se concatenan dentro de un IIFE y comparten el objeto `NX`:

- `NX.ns`: namespace del juego, o `null` hasta que se captura.
- `NX.onNS(fn)`: corre `fn(ns)` apenas se captura el namespace, o en el acto si ya existe.
- `NX.store.get(key, def)` / `NX.store.set(key, value)`: JSON en `localStorage` con el prefijo.
- `NX.feature({ key, label, needs: ns => bool, setup: ns => void })`: registro con la red de seguridad.
- `NX.trip(key, err)`: reporta un error de dibujo, y 20 en 10 s apagan el módulo.
- `NX.isOn(key)`: falso si el módulo está roto, falta o fue desactivado por el usuario.
- `NX.me()`, `NX.inRun()`, `NX.shown(id)`: ayudas de estado del juego.
- `NX.hudLayers`: arreglo de `{ key, under(ctx, w, h, player), over(ctx, w, h, player) }` que el núcleo dibuja al envolver `HUD.draw`.
- `NX.settings.section({ key, title, render(el) })`: agrega una sección al panel.
- `NX.keys.bind(test(e), fn(e))`: atajos globales, ignorados si el foco está en un campo de texto.

## Tareas

1. **Build y núcleo.** `scripts/build.mjs`, `src/core/{head,store,util,hook,features,hud,keys,settings,tail}.js`. Prueba: `node scripts/build.mjs` genera `dist/mod.js`, `dist/version.json` y `extension/mod.bundled.js`, y `node --check dist/mod.js` pasa.
2. **Cascarón.** `extension/{manifest.json,background.js,popup.html,popup.js}`. Prueba: `node --check` en los JS y validación del JSON del manifiesto.
3. **Módulos.** `src/features/{fov,sharpness,minimap,shortcuts,combat}.js`, cada uno registrado con `NX.feature` y con su sección en el panel.
4. **Verificación de humo.** Chrome sin interfaz inyecta `dist/mod.js` con un init script en pokesurvivor.com y lee `window.__nexus.status()`. Esperado: namespace capturado y ningún módulo "roto".
5. **README, release 0.1.0, commit y push.**
